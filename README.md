# SAD-OTR / GHEM-AC Supplementary Simulator

Reviewable artifact for the IEEE TNSM manuscript *Schedule-Aware Dynamic
Optical Topology Reconfiguration for Scale-Out AI Data Center Fabrics*.

## Contents

- `sad_otr/` — demand generators (Section V), closed-form `T(D,E)` with
  **source and destination** packet capacity, MILP (PuLP/CBC), GHEM-AC
  (`WeightGreedy`, `BottleneckFill`, `BisectTarget`) and optional
  `LocalSwapRepair` post-repair for worst-gap mitigation.
- `sad_otr/baselines.py` — literature baselines under the same constraints and
  accounting: EPS, MWM per phase (c-Through/Helios style, K rounds of
  Hungarian matching), Solstice-K (QuickStuff + BigSlice, K-port), Eclipse-K
  (greedy gain/(alpha+delta), best prefix), RotorNet-style rotation (duty 0.9,
  direct one-hop) and the ideal non-blocking lower bound.
- `sad_otr/multislot.py` — retiming LP (HiGHS via SciPy) for any slice
  sequence, Eclipse-style slice generator, and SAD-OTR-TM (slice-level
  amortization; first slice = GHEM-AC decision, charged only if it changes).
- `sad_otr/demands.py` — also provides the skewed EP family
  (`expert_skewed`, Zipf s=1, fan-out 8) used in the scalability study.
- `scripts/` — table / ablation / multi-seed / noise / latency runners, plus
  `run_baselines.py`, `run_scalability.py`, `run_robust.py` and
  `generate_figures_q1.py` (Q1 revision).
- `results/` — JSON/CSV outputs generated by the scripts.
- `sad_otr/llm_workload.py` — model-derived workload from published DeepSeek-V3
  dimensions; `sad_otr/inputs_io.py` — npz save/load of phase sequences.
- `tools/` — table-row generator and manuscript verifiers.
- `sad_otr/llm_workload.py` — model-derived workload from published DeepSeek-V3 dimensions; `sad_otr/inputs_io.py` — npz save/load of phase sequences.

## Environment

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Requires CBC via PuLP (`PULP_CBC_CMD`).

## Defaults

`N=32`, `K=4`, `B_opt=800` Gbps, `B_eps=400` Gbps, `delta=15` ms, 12 phases,
`seed=0` for main tables. Bisection absolute tolerance `ε=1e-9` s.

## Model notes

- **Destination EPS capacity:** both `∑_j f^eps_ij ≤ B_eps·T` and
  `∑_i f^eps_ij ≤ B_eps·T` in the MILP and in `eq:feas`.
- **Static OCS baseline:** `WeightGreedy` on phase-1 demand, held fixed.
- **Unsplittable mode:** all-or-nothing per demand (ablation).
- **LocalSwapRepair:** optional fourth path — local edge add/swap repair on
  the best of the three candidates before amortization (`use_repair=True`).
- **CBC settings:** `timeLimit` 120 s (60 s in run_scalability.py), `gapRel=0`, `threads=1`; MILP
  latency includes PuLP model build + CBC solve.
- **Latency methodology:** CPython `time.perf_counter`; GHEM-AC warm-up
  discarded then median of reps; Table II uses mean wall time over the
  12-phase suite.

## Reproduce

Layout of the Overleaf package: `code/` (this directory), `results/` (the raw
outputs used in the paper), `inputs/` (exported generated inputs) and the
manuscript `bare_jrnl.tex` with its `fig_*.pdf` at the top level. Run scripts
from `code/`. They write to `code/results/` (created if missing), so the
paper's copies in `../results/` are not overwritten. Post-processing scripts
(`run_significance.py`, `tools/make_tables.py`) read `code/results/`: run the
corresponding simulation first, or `cp ../results/* results/` to post-process the
stored outputs. Figure scripts write to
`../figures/`; copy the PDFs to the top level to rebuild the manuscript.

```bash
cd code
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
# fastest check (about 1 min): headline Table VI inputs -> numbers
python scripts/reproduce_headline.py --inputs ../inputs --llm
# every number in the manuscript against ../results
python tools/verify_manuscript.py ../bare_jrnl.tex ../results
```

### Inputs

Workloads are generated deterministically from (generator, N, seed) by
`sad_otr/demands.py` and `sad_otr/llm_workload.py`. `scripts/export_inputs.py`
writes the exact matrices used (in Gb per rack pair, one `.npz` per run, keys
`D00..D11` and `kinds`; read them with `sad_otr.inputs_io.load_phases`):
`inputs/primary/` (N=32 seeds 0–9; N=8..28 seed 0), `inputs/scalability/`
(uniform and skewed, N=16..256), `inputs/llm/` (DeepSeek-V3-derived, seeds
0–9) and `inputs/robust/` (the perturbed estimates of the uncertainty study).
Transfer-size, delta, K and B_eps sweeps rescale or reuse the seed-0 primary
matrices (see `inputs/config.json`).

### Environment and determinism

Environment used for the reported numbers: Python 3.13.5, NumPy 2.5.3,
SciPy 1.18.1, PuLP 3.3.2 (CBC 2.10.3), Matplotlib 3.11.2, 8-vCPU Intel Xeon.
Decision latencies are machine dependent. All completion times are deterministic
given the seeds, except that LP ties can occasionally resolve differently
(observed once: delta=0.1 ms SAD-OTR-TM, 0.5122 s in `baselines_delta.csv`
against 0.5123 s in `tm_smalldelta.json`). Statistics: Student-t 95% confidence
intervals over seeds; ratios between schemes are paired per seed; paired
t-test on log times and exact Wilcoxon signed-rank test with Holm adjustment.
